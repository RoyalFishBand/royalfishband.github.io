Articles That Need to Be Written

To add an article, write it in a properly formatted HTML document in the main branch of the Github repository. Make sure the filename is exactly as it appears here, plus .html on the end. This is because many of these articles are already linked on other pages. Some entries in this list include [bracketed] suggestions of article titles that differ slightly from their link. Otherwise, title the article as it appears in the link, replacing dashes [-] with spaces. Make sure all article titles are in titlecase. If you don't know how to do that (or are afraid of messing up the wiki,) send your article to royalfishband@gmail.com.


This official wiki is run and moderated by the band themselves. To request access, submit the google form linked on the homepage. We will give you access to the github repository where this site is hosted. Tutorials are in the works for people who don't know HTML, but still want to contribute.
